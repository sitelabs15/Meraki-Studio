# Meraki Inkflow

He conservado del hero de Wonderkin la navegación mínima, el titular serif de gran escala, el retrato central recortado en arco y la superposición de elementos visuales, transformándolo en una identidad monocromática propia para no crear una copia literal. El proyecto de referencia utiliza una estética oscura, editorial e inmersiva, combinando portafolio y conversión.

3. IDENTIDAD VISUAL
────────────────────────────────────────

Crear una identidad predominantemente monocromática.

Paleta principal:

- Fondo carbón principal: #171717

- Superficie elevada: #202020
- Blanco cálido principal: #F2F0EA
- Blanco secundario: #D8D6D0

- Gris oscuro para bordes: #353535
- Bordes claros: rgba(242, 240, 234, 0.18)
- Overlay oscuro: rgba(10, 10, 10, 0.55)

No usar negro puro #000000 como fondo dominante. El sitio debe sentirse oscuro, pero conservar detalle, textura y profundidad.

No introducir colores saturados. Todo el sitio debe mantener una estética en blanco, gris, negro carbón y marfil.

Se permite un grano visual muy fino y sutil sobre el fondo para evitar superficies completamente planas. La textura debe ser discreta, con una opacidad aproximada del 2% al 4%, sin afectar la legibilidad ni el rendimiento.

Estilo general:

- Editorial.
- Minimalista.
- Artístico.
- Atemporal.
- Sensual sin ser explícito.
- Oscuro sin sentirse lúgubre.
- Premium sin resultar pretencioso.
- Mucho espacio negativo.
- Jerarquía tipográfica marcada.
- Fotografías protagonistas.
- Líneas divisorias delgadas.
- Componentes con pocos bordes redondeados.
- Evitar tarjetas genéricas con excesivo border-radius.
- Utilizar esquinas rectas o radios discretos de 2px a 8px.
- Reservar la forma de arco para elementos importantes, especialmente el hero.

- El logotipo debe funcionar en blanco cálido sobre fondo carbón.

- No usar íconos de aguja, máquina de tatuaje, corazón o mariposa como parte del logotipo.
- El resultado debe sentirse como la firma personal de una artista.

Tipografías sugeridas:

Logotipo:
- Italianno, Parisienne o una alternativa de Google Fonts con apariencia de firma elegante.
- Evitar tipografías cursivas infantiles, románticas en exceso o difíciles de leer.

Titulares editoriales:
- Cormorant Garamond.
- Bodoni Moda.
- Instrument Serif.
- Elegir una sola familia principal para mantener coherencia.

Texto de interfaz y cuerpo:
- Manrope.
- Inter.
- Plus Jakarta Sans.
- Elegir una sola familia sans serif.

Combinación preferida:

- Logotipo: Italianno.
- Titulares: Cormorant Garamond.
- Cuerpo e interfaz: Manrope.

Jerarquía aproximada:

- Hero H1 en escritorio: clamp(5rem, 10.5vw, 11rem).
- Hero H1 en móvil: clamp(3.5rem, 17vw, 6rem).
- Títulos de sección: clamp(3rem, 6vw, 6.5rem).
- Subtítulos: 1.25rem a 1.75rem.
- Cuerpo: 1rem a 1.125rem.
- Etiquetas: 0.7rem a 0.8rem, mayúsculas, tracking de 0.14em a 0.22em.

Los textos grandes deben mantener un line-height compacto, entre 0.85 y 0.98.
